# Amazon E-Commerce Website Clone

A beginner-friendly Amazon website clone built using **HTML, CSS, and JavaScript**, following the hands-on learning approach of SuperSimpleDev.

This project helped me practice front-end web development by building e-commerce features and implementing real JavaScript functionality.

## 🚀 Features

- **Product Listing:** Display products with images, names, prices, and ratings.
- **Shopping Cart:** Add products to the cart and manage cart items.
- **Quantity Management:** Update product quantities in the cart.
- **Order Management:** Place orders and view order details.
- **Order Tracking:** View order information and tracking details, if implemented.
- **Buy Again:** Add previously ordered products to the cart, if implemented.
- **Search Functionality:** Search for products.
- **URL Parameters:** Pass and read search information using URL query parameters.
- **Asynchronous JavaScript:** Practice promises, `async`/`await`, and `fetch()`.
- **Backend Requests:** Practice sending HTTP GET and POST requests.
- **DOM Manipulation:** Update webpage content dynamically using JavaScript.

## 🛠️ Technologies Used

- HTML5

- Git and GitHub
- Fetch API and asynchronous JavaScript
